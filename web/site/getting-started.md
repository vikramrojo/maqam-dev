## Getting started

1. **Try it first, if you like.** The [emulator](../emu/) runs the real firmware in a web page: no FM-1 needed. The screens below are its screens.
2. **Your music is kept.** Your projects, presets, samples and settings are kept when you install, so a backup is optional (the update also keeps projects from earlier versions of Maqam's base firmware; see the home page).
3. **Install.** Connect the FM-1 by USB, open the [installer](../installer/) in Chrome or Edge and press **Install**. Do not unplug the cable while it writes. If an install is interrupted, press Install again; if the FM-1 no longer starts, hold OCT− alone while switching it on (USB rescue) and install again.
4. **Play a maqam in two moves.** Hold **SEL**, turn **PRESETS** to `arab`, turn **KNOB 2** to a maqam, set **KNOB 3** to `white`, and press the root key; let go and play the white keys up and down. The rest of this page explains every control.
